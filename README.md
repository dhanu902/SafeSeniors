# SafeSeniors Edge AI Fall Detection System

## 📌 Project Overview
SafeSeniors is an Edge AI-based fall detection system designed to monitor elderly individuals using smartphone sensors.

The system uses accelerometer and gyroscope data to detect fall events in real-time and send alerts to caregivers.

## 🧠 Key Features
- Real-time fall detection using ML
- Edge AI inference on Android device
- Cloud-based alert storage
- Caregiver dashboard

## 🏗️ System Architecture
Smartphone Sensors → Edge AI → Cloud → Dashboard

## ⚙️ Technologies Used
- Android (Java/Kotlin)
- TensorFlow Lite
- Python (Model Training)
- Flask (Backend API)
- Firebase / REST API

## 📊 Machine Learning
- Model: Random Forest 
- Features: acceleration, orientation change
